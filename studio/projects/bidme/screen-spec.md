# Bidme Screen Specification

각 화면은 목적, 사용자의 감정, 핵심 정보, Primary/Secondary action, AI 문구, Loading·Empty·Error·접근성·개발 주의사항을 정의한다.

## Customer Home

목적은 “무엇을 요청할지” 바로 시작하게 하는 것이다. Primary는 요청 시작, 보조 영역에는 최근 요청과 진행 상태를 둔다. 빈 상태에는 예시 요청을 제공한다.

## AI Request

자유 입력을 허용하되 예시와 선택지를 함께 제공한다. AI는 누락된 조건만 질문하고 제출 전 요약과 수정 기회를 제공한다.

## Proposal List

가격, 일정, 평점, 포함 범위를 비교 가능한 구조로 보여준다. 추천 이유는 근거와 함께 표시하고 선택 전 상세를 열 수 있어야 한다.

## Reservation

선택한 공급자·서비스·일정·비용을 확인한 뒤 예약을 확정한다. 최종 action은 명확한 확인 문구와 취소 경로를 가진다.

## Provider Home

새 요청, 응답 대기, 진행 중 서비스를 우선순위로 보여준다. Primary는 응답할 요청 열기이며, 상태와 다음 행동을 함께 표시한다.
