# Bidme Project Design Book

Bidme는 고객의 SEARCH를 공급자의 REQUEST로 연결하고, AI가 요청을 정리하고 제안을 비교하도록 돕는 첫 적용 프로젝트다.

## 경험 목표

- 고객: 원하는 결과를 빠르게 설명하고 신뢰할 수 있는 제안을 선택한다.
- 공급자: 요청의 의도를 이해하고 실행 가능한 제안을 보낸다.
- AI: 입력을 정리하고 누락 정보를 질문하며 비교를 돕는다.

공통 원칙은 `../../design-book/`을 따르고 프로젝트 의사결정은 이 폴더의 문서에 기록한다.
