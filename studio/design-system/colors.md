# Colors

색은 의미 중심으로 사용한다. 공통 semantic color를 먼저 선택하고 프로젝트 브랜드 색은 토큰으로 확장한다.

| Token | 용도 |
|---|---|
| Primary | 핵심 행동과 브랜드 강조 |
| Secondary | 보조 행동 |
| Success / Warning / Error / Info | 상태와 안내 |
| Surface | 페이지·카드·오버레이 배경 |
| Text | 본문·보조·비활성 텍스트 |
| Border | 구분선과 입력 경계 |
| Disabled | 조작 불가 상태 |

초기 값은 실제 화면 검증 전까지 확정하지 않는다. 대비를 먼저 검증하고 프로젝트별 색상은 의미 토큰 뒤에 매핑한다.
