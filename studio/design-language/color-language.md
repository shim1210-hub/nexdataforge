# Color Language

색은 장식이 아니라 의미를 전달한다. 먼저 상태와 행동의 목적을 정한 뒤 색을 선택한다.

| 언어 | 목적 |
|---|---|
| Primary | 핵심 행동과 브랜드 방향 |
| Success | 완료·안심·정상 진행 |
| Warning | 주의가 필요하지만 진행 가능한 상태 |
| Danger | 손실·삭제·위험·복구가 필요한 상태 |
| Surface | 정보의 층과 읽기 영역 |
| Text | 정보의 중요도 |
| Border | 구분과 입력 경계 |
| Disabled | 현재 조작할 수 없는 상태 |
| AI | AI가 제안하거나 처리 중임을 구분 |
| Proposal / Reservation / Review | 제품 도메인의 의미 토큰 |

좋은 사용은 색과 문구·아이콘·위치를 함께 사용한다. 색상만으로 성공·오류·선택을 전달하지 않는다. 프로젝트 색상은 semantic token 뒤에 매핑한다.
