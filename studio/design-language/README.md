# NexDataForge Design Language

Design Language는 NexDataForge 제품이 사용자에게 일관된 의미와 행동을 전달하도록 만드는 시각·상호작용 언어다. 단순한 색상표나 컴포넌트 목록이 아니라, **무엇을 보고 무엇을 느끼며 다음에 무엇을 해야 하는지**를 결정하는 공통 문법이다.

## 왜 필요한가

제품마다 화면이 달라도 핵심 행동, 상태, 신뢰, AI의 역할을 예측할 수 있어야 한다. Design Language는 프로젝트의 개성을 제한하지 않고, 경험의 기본 방향을 공유하게 한다.

## Design System과의 차이

Design Language는 의미와 사용 원칙을 정의한다. Design System은 그 원칙을 토큰·컴포넌트·코드로 구현한다. Language가 “Primary는 결정적 행동을 강조한다”고 말하면 System은 색상 토큰, 버튼 규격, 상태를 제공한다.

## Design Book과의 관계

Design Book은 Experience First, 명확성, 신뢰, AI 보조, 접근성 같은 판단 철학을 담는다. Design Language는 그 철학을 색·타입·간격·형태·모션·레이아웃·컴포넌트 언어로 번역한다. Project Design Book은 이를 제품 흐름에 적용하고 예외를 기록한다.

## 사용 순서

1. 사용자 목표와 상태를 정한다.
2. 이 폴더에서 의미에 맞는 언어를 고른다.
3. `design-system/`의 토큰과 컴포넌트로 구현한다.
4. 프로젝트 문서에 적용 이유와 예외를 기록한다.
5. Design Review에서 일관성·접근성·복구 가능성을 검토한다.

## 문서 규칙

각 문서는 철학, 사용 목적, 좋은 사용, 피해야 할 사용, 프로젝트 적용 예시를 포함한다. 값은 화면 검증 전 확정하지 않으며, 공통 언어와 프로젝트 확장을 분리한다.
