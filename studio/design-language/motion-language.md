# Motion Language

Motion은 예쁘게 보이기 위한 효과가 아니라 상태 변화와 다음 행동을 이해시키는 신호다.

Loading은 기다림의 위치를, Searching은 탐색 중임을, Success는 완료와 다음 행동을, Failure는 복구 경로를 보여준다. Proposal Arrival, AI Thinking, Reservation Complete, Chat은 각 상태의 원인과 결과가 연결되도록 한다.

모션이 없어도 같은 정보가 전달되어야 하며 `prefers-reduced-motion`을 존중한다. 긴 반복 애니메이션과 목적 없는 장식 모션은 사용하지 않는다.
