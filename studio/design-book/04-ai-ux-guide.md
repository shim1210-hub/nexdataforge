# AI UX Guide

## AI의 역할

요청 이해, 입력 보조, 누락 정보 질문, 결과 요약, 선택지 비교, 다음 행동 안내에 사용한다.

## AI가 하지 않는 일

사용자 결정을 확정하지 않고, 사실이 아닌 값을 사실처럼 생성하지 않으며, 과도한 자동화로 작업을 방해하지 않는다. 불확실성과 기술 오류는 사용자에게 숨기지 않는다.

## 대화 규칙

- 짧고 구체적으로 말한다.
- 명령형보다 제안형을 사용한다.
- 중요한 정보는 구조화한다.
- 결과에는 다음 행동을 함께 제시한다.
- 실패 시 원인, 책임, 복구 방법을 분리해 안내한다.

좋은 표현: “요청을 이해했어요. 지역과 희망 날짜를 알려주시면 더 정확히 찾아볼게요.”

피해야 할 표현: “완벽한 결과입니다. 그대로 진행하세요.”
