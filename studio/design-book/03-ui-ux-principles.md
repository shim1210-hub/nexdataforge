# UI/UX Principles

- 시각적 계층은 제목, 본문, 보조 정보 순으로 분명하게 둔다.
- Primary, Secondary, Tertiary action은 색·위치·강도로 구분한다.
- Card는 독립된 판단 단위일 때만 사용한다.
- 목록은 비교와 탐색을, 상세 화면은 이해와 결정을 담당한다.
- Modal은 짧은 확인, Drawer는 보조 작업, Full Screen은 집중 작업에 사용한다.
- 입력은 최소화하고 라벨·도움말·오류를 입력 가까이에 둔다.
- 모바일 터치 영역은 최소 44px을 목표로 한다.
- Safe area, 키보드, 스크롤, 작은 Android 화면을 검토한다.
- 상태 Badge는 의미가 있을 때만 사용하고 색만으로 상태를 전달하지 않는다.
