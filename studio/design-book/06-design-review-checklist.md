# Design Review Checklist

- [ ] 화면의 사용자 목표와 Primary action이 3초 안에 보인다.
- [ ] 정보 구조와 제목 계층이 자연스럽다.
- [ ] 행동 우선순위가 Primary / Secondary / Tertiary로 구분된다.
- [ ] 입력값 보존, 오류 위치, 복구 방법이 정의되어 있다.
- [ ] Loading, Empty, Success, Error 상태가 있다.
- [ ] 중복 조작과 취소·되돌리기가 처리된다.
- [ ] AI 결과를 사용자가 확인·수정할 수 있다.
- [ ] 키보드·스크린 리더·대비·터치 영역을 검토했다.
- [ ] 작은 모바일 화면과 느린 네트워크를 검토했다.
- [ ] 구현 가능한 컴포넌트와 개발 주의사항이 명시되어 있다.
