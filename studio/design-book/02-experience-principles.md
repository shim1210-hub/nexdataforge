# Experience Principles

모든 흐름은 다음 질문에 답해야 한다.

- 첫 3초 안에 화면의 목적이 보이는가?
- 첫 행동까지의 단계가 최소한인가?
- 입력보다 선택, 선택보다 자동완성을 우선할 수 있는가?
- 자동완성 뒤에 사용자가 내용을 확인할 수 있는가?
- 오류가 입력값을 보존하고 복구 방법을 알려주는가?
- 로딩 중 중복 조작을 막고 현재 상태를 보여주는가?
- 성공 후 다음 행동이 명확한가?
- 취소와 되돌리기가 가능한가?
- Empty State가 다음 행동을 제공하는가?

각 원칙은 **원칙 / 이유 / 좋은 예 / 피해야 할 예 / 개발 확인 항목** 형식으로 확장한다.
